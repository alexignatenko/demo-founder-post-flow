# Джобы основателей — демонстрационная версия

В реальном прогоне было восемь джобов из одного JTBD-файла. Ниже сохранены их ID и основные смыслы, но удалены имя респондента и сведения об исходной встрече. Это пример входа, а не файл, подключённый к flow.

| ID | Боль основателя | Какое решение он хочет принять |
|---|---|---|
| job1 | Не хватает надёжной экономики платного привлечения: ROAS, LTV, допустимого CAC/CPA. | Понять, какие каналы можно прибыльно масштабировать. |
| job2 | Сложно оценить работу UA-менеджеров на дистанции. | Решить, кого оставить в команде и какой подход к закупке менять. |
| job3 | Просадку экономики закупки замечают поздно. | Быстро находить аномалии по когортам, гео и тарифам. |
| job4 | Внедрение аналитики долго не приносит пользы, хотя оплата уже идёт. | Получить рабочий минимум быстро и расширять его поэтапно. |
| job5 | Данные регулярно ломаются, и основатель становится тестировщиком системы. | Получать надёжные данные без постоянного личного контроля. |
| job6 | Долгая SaaS-подписка может обходиться дороже своего решения. | Сравнить совокупную стоимость и выбрать подходящий вариант. |
| job7 | Аналитика, собранная без технической опоры, может оказаться хрупкой. | Обеспечить поддержку SQL, кода и архитектуры после запуска. |
| job8 | Ремонт аналитики съедает внимание, нужное для роста бизнеса. | Ограничить аналитику конкретными вопросами и вернуться к продуктовым и маркетинговым решениям. |
