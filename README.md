# Демонстрация: как flow выбирает русский пост

Это локальный набор для показа процесса на **реальном прогоне 8 октября 2026 года** (`2026-10-08_d5fcb55b`). Здесь нет токенов, транскриптов встреч и прямых ссылок на собеседников. Пример карточки истории сокращён и обезличен; оценки взяты из исходного прогона и для сокращённой карточки заново не вычислялись.

Откройте [светлую блок-схему](./схема.png) (рядом есть редактируемая SVG-версия). Она показывает фактическую цепочку: 19 историй × 8 джобов → 152 пары → 10 пар с подходящей болью → 8 идей → 7 прошедших проверку → 5 разных историй → кандидат № 1 → 3 версии поста.

## Что лежит в папке

| Файл | Роль в процессе |
|---|---|
| `01-vhodnye-faily/пример_истории.md` | Обезличенный пример карточки, которую читает поиск кандидатов. До запуска flow такие карточки готовит скилл `meeting-stories`. |
| `01-vhodnye-faily/джобы_основателей_пример.md` | Демонстрационная версия восьми JTBD-записей с теми же ID и смыслом, что в прогоне. |
| `01-vhodnye-faily/правила_контента_telegram.md` | Полная копия действующего файла правил Telegram-поста. Длина в этом flow не ограничивается. |
| `01-vhodnye-faily/эталоны_сторителлинга.md` | Полная копия эталонов подачи истории; они служат стилевым ориентиром, не источником фактов. |
| `02-skilly/meeting-stories_SKILL.md` | Полная копия скилла, который извлекает истории из реальных встреч и сохраняет карточки. Он работает **до** flow. |
| `02-skilly/no-ai-slop_SKILL_upstream.md` | Полная копия правил редакторской чистки, которые читает писатель/редактор. |
| `03-rezultat/оценки_и_выбор.md` | Цифры и решения из одного прогона; указано, что было отклонено и чего нет в логах. |
| `05-one-post/` | Пять отдельных файлов про **одного** кандидата: джоб → история → идея → хук → пост. Пост — обезличенная демонстрационная версия, не дословный вывод flow. |
| `голос_экспертный_не_подключен.md` | Копия существующего гайда авторского голоса, вынесенная в корень папки для удобства показа. Он предназначен для LinkedIn/блога и **не подключён** к этому Telegram-flow. |

## Важные ограничения этой демонстрации

- Пять показанных хуков относятся к **пяти разным идеям**. Промежуточные варианты хуков для каждой идеи в JSON прогона не сохранены.
- Кандидат № 1 стал первым по оценке идеи (0,828). У кандидата № 3 оценка хука выше (0,861 против 0,838), но это не делает его победителем по общей оценке идеи.
- Все три версии поста № 1 провалили хотя бы один порог Jev. Flow взял лучшую из них (0,267) на финальную правку. После неё Jev повторно не запускался. Статус `ready` не равен прохождению всех проверок.
- Цитаты/хайлайты для поста могут подтягиваться из локальной базы Readwise/Roam; это **не отдельный Markdown-файл** в этом наборе.
- Исходный транскрипт встречи не включён: карточка истории — вход для отбора, а ограниченный фрагмент встречи может быть прочитан только позже, при написании выбранного поста.
